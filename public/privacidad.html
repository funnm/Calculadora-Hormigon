Política de Privacidad

Esta política explica como Concrete Design Pro gestiona datos del usuario, proyectos, preferencias, almacenamiento local, exportaciones y servicios necesarios para operar la aplicacion.

Ultima actualizacion26 de mayo de 2026

Control del usuarioEl usuario conserva control sobre datos locales y archivos exportados.
No vendemos datosNo comercializamos proyectos, modelos, reportes ni informacion tecnica ingresada.
Uso tecnicoLa informacion se usa para calcular, documentar, guardar preferencias y mejorar la experiencia.

1. Alcance

Esta politica aplica al uso de Concrete Design Pro, herramienta web orientada a diseno de mezclas de hormigon, granulometria, volumen absoluto, resistencia, aditivos y reportes tecnicos, desarrollada por Paul R.

2. Informacion tratada

Datos tecnicosdatos de obra, responsables, materiales, granulometrias, resistencias, dosificaciones, aditivos, historial local y archivos exportados.
PreferenciasTema, idioma, unidades, vistas, configuraciones de calculo, paneles activos y estado de interfaz.
ExportacionesReportes, imagenes, hojas de calculo, JSON, PDF u otros archivos generados por el usuario.
Datos de navegadorCache, almacenamiento local, recursos estaticos y datos tecnicos necesarios para ejecutar la aplicacion.

3. Finalidad

La informacion se utiliza para ejecutar calculos, construir modelos, mantener continuidad entre sesiones, generar documentos, recordar preferencias y permitir que el usuario revise o exporte sus resultados.

4. Almacenamiento local

La aplicacion puede usar LocalStorage del navegador para conservar proyectos, preferencias, historial y configuraciones de calculo. El usuario puede borrar estos datos desde la configuracion del navegador o reiniciando el estado de la aplicacion cuando esa opcion exista.

5. Servicios y dependencias

La aplicacion trabaja principalmente en el navegador y puede usar dependencias de exportacion como jsPDF, hojas de calculo y librerias de graficos.

6. Seguridad

No introduzca informacion confidencial innecesaria en nombres de proyecto, notas, responsables, clientes o archivos. Revise cada exportacion antes de compartirla.

7. Derechos y control

El usuario puede evitar ingresar datos personales, borrar almacenamiento local, descargar o eliminar archivos generados y solicitar orientacion sobre privacidad escribiendo al correo oficial.

8. Contacto

Para consultas de privacidad escriba a elzucoing2002@gmail.com.
