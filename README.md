# Concrete Design Pro

**Autor:** Paul R  

Calculadora sencilla para estimar fundas de cemento, arena, grava y agua segun volumen de hormigon. La tabla base toma como referencia el archivo `Dosificacion_Hormigones_Holcim_Calculadora_Volumen1.xlsx` y permite ajustar el peso de la funda para distintos cementos.

## Comandos

```bash
npm install
npm run dev
npm run build
```
